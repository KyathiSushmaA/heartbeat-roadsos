# CardioGuard ❤️

AI-powered emergency response system for road accident victim monitoring.

## Project Overview

CardioGuard is built for the National Road Safety Hackathon 2026 under the RoadSoS problem statement.

The application helps detect emergencies after road accidents and provides real-time victim monitoring.

## Features

* Emergency SOS trigger
* Simulated heartbeat monitoring
* Simulated oxygen level monitoring
* AI severity prediction
* Nearby hospital and ambulance lookup
* Emergency alert dashboard

## Tech Stack

Frontend:

* HTML
* CSS
* JavaScript

Backend:

* Python Flask

Machine Learning:

* Scikit-learn Decision Tree Classifier

Optional Integrations:

* Google Maps API
* Twilio SMS API
* Firebase

## Installation

Clone project:

git clone https://github.com/KyathiSushmaA/heartbeat-roadsos.git

Install packages:

pip install flask
pip install flask-cors
pip install scikit-learn
pip install pandas
pip install numpy

Run backend:

cd backend
python app.py

Run frontend:

Open frontend/index.html using Live Server in VS Code.

## Demo Flow

1. Accident occurs
2. CardioGuard detects emergency
3. Live vitals are monitored
4. AI predicts severity
5. Nearby emergency services alerted
6. Hospital receives live patient vitals before arrival
